오사카 미식 지도

숙소: 리가 로열 호텔 오사카 (나카노시마)

🧭 호텔로 돌아가는 길

지도 종류

오프라인 대비 (로밍·지하용)

우메다·후쿠시마·나카노시마·난바 일대 지도를 휴대폰에 미리 저장합니다. 숙소 Wi-Fi에서 한 번 눌러 두세요.

핀 색깔 (타베로그 기준, 구글순일 때는 구글 기준)

3.75 이상 · 구글 4.4+3.65 이상 · 4.2+3.55 이상 · 4.0+그 외

핀에 휴가 붙거나 회색이면 고른 요일에 쉬는 날(또는 오늘 영업이 끝난) 가게입니다. ★는 찜한 곳.

데이터 안내

평점·영업시간·위치는 2026-11-05 웹 확인 기준 참고값입니다. 방문 전 Google 지도·타베로그에서 한 번 더 확인하세요. 거리는 직선거리, 도보 시간은 직선거리×1.3을 시속 4.5km로 계산한 어림값입니다.

내 위치가 안 나올 때

아이폰 (Safari)

  1. 설정 앱 → 개인정보 보호 및 보안 → 위치 서비스 켜기
  2. 같은 화면 아래 Safari 웹 사이트 → 앱을 사용하는 동안 (정확한 위치 켜기)
  3. Safari 주소창의 가가(또는 ⋯) → 웹 사이트 설정 → 위치 → 허용

안드로이드 (Chrome)

  1. 휴대폰 상단 빠른 설정에서 위치 켜기
  2. Chrome 주소창 왼쪽 아이콘 → 권한(사이트 설정) → 위치 → 허용

카카오톡·라인 안에서 열었다면

앱 안의 브라우저는 위치 권한이 막힐 때가 많습니다. 오른쪽 위 메뉴에서 다른 브라우저로 열기를 눌러 Safari·Chrome에서 여세요. 홈 화면에 추가해 두면 앱처럼 바로 열 수 있습니다.

지하상가·건물 안

GPS가 약해서 위치가 수십~수백 m 틀릴 수 있습니다(파란 원이 클수록 부정확). 지상으로 나오면 금방 정확해집니다. 그동안은 정렬 기준을 지도 중심으로 바꾸고 지도를 원하는 곳으로 옮겨 쓰세요.
